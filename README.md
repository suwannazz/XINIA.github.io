เว็บไซต์แก๊ง FiveM สไตล์ Cybernetic Underworld ระดับพรีเมียม (ไม่ซ้ำใคร แต่คงความดุดัน หรูหรา เท่ห์กว่าเดิม) พร้อมระบบเครื่องเล่นเพลงที่รองรับ **ลิงก์ YouTube และเลือกท่อนเริ่มเพลงได้**, ระบบโลโก้ 3 มิติ (Three.js) และระบบหลังบ้าน (Admin Dashboard) สลับใช้ได้หลายแก๊ง

## 🚀 วิธีเปิดใช้งาน (How to Run)

1. เปิด Terminal หรือ PowerShell ในโฟลเดอร์นี้
2. เริ่มต้นรันเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
3. เปิดเบราว์เซอร์เข้าใช้งาน:
   - 🌐 **หน้าแรก (Home Page):** [http://localhost:3000](http://localhost:3000)
   - 👥 **หน้าฐานข้อมูลสมาชิก (Operatives Database):** [http://localhost:3000/members](http://localhost:3000/members)
   - ⚙️ **ระบบหลังบ้าน (Admin Dashboard):** [http://localhost:3000/admin](http://localhost:3000/admin)

## ✨ ไฮไลต์ฟังก์ชันใหม่ตามที่ขอ

### 1. 🎵 ระบบเพลง YouTube พร้อมเลือกท่อนเริ่มเพลง (Timestamp Selector)
- **ใส่ลิงก์ YouTube ได้โดยตรง:** รองรับทั้ง `https://www.youtube.com/watch?v=...` และ `https://youtu.be/...`
- **เลือกท่อนเริ่มเพลงได้:** กรอกเป็นเวลา เช่น `0:45` หรือ `45` วินาที ระบบจะกระโดดไปเล่นที่ท่อนฮิต/ท่อนดรอปนั้นทันที
- **เลือกท่อนจบและวนลูป (Loop Section):** กำหนดท่อนจบ เช่น `1:30` เพื่อให้เพลงวนลูปเฉพาะท่อนคอรัสได้อัตโนมัติ
- **ปุ่มทดสอบฟังในหน้า Admin:** มีปุ่ม `▶ ทดสอบฟังท่อนนี้` ให้แอดมินกดฟังตัวอย่างสดๆ ก่อนบันทึก
- **ดึงรูปปกเพลงอัตโนมัติ:** เมื่อวางลิงก์ YouTube ระบบจะดึงภาพปก (Thumbnail) มาแสดงบนวิดเจ็ตเพลงให้อัตโนมัติ

### 2. 💎 UI/UX สไตล์ Cybernetic Tactical (ดีไซน์เฉพาะตัว เท่กว่า ไม่ซ้ำใคร)
- **#gang-name (ชื่อแก๊งค์):** แสดงชื่อแก๊งตัวอักษร 3D Perspective Metallic Chrome ไล่เฉดสีเงินไทเทเนียม พร้อมคำขวัญแก๊ง (Gang Motto) และออราแสงนีออน
- **แท่นโฮโลแกรม 3 มิติ (Hologram Pedestal & Rings):** วงแหวนโฮโลแกรม Cybernetic หมุนซ้อนกันรอบโลโก้ 3D พร้อมละอองอนุภาค (Nebula Particle Vortex)
- **Tactical HUD Bar:** แถบสถานะด้านบน `SYS_STATUS: OPERATIONAL` พร้อมเรดาร์กระพริบ และปุ่มคัดลอก IP เซิร์ฟเวอร์ FiveM
- **แผงสถิติสด (Quick Stats):** แสดงจำนวนสมาชิกที่ออนไลน์และผู้บังคับบัญชาแบบ Real-time
- **ระบบเสียงเอฟเฟกต์ (Cyber SFX):** สังเคราะห์คลื่นเสียงไฮเทคผ่าน Web Audio API เมื่อเลื่อนเมาส์ผ่านปุ่มหรือการ์ด

### 3. 👥 หน้าฐานข้อมูลสมาชิก (Operatives Database)
- **การ์ดสมาชิกสไตล์ Tactical Dossier:** ดีไซน์การ์ดสไตล์สายลับสุดดุดัน มีเอฟเฟกต์สะท้อนแสงโฮโลแกรม (Foil Shimmer) เมื่อเลื่อนเมาส์ผ่าน
- **ระบบแบ่งหมวดหมู่แบบปุ่ม Filter Pills:** สลับดูเฉพาะ `ALL SQUADS`, `01 FOUNDERS`, `02 LEADERS`, `03 OPERATIVES`
- **ช่องค้นหา HUD:** พิมพ์ค้นหาชื่อหรือตำแหน่งได้แบบทันที (Real-time Instant Search)
- **ช่องทางติดต่อ:** ลิงก์ตรง Facebook และรหัส Discord

### 4. ⚙️ แผงควบคุมระบบหลังบ้าน (Admin Dashboard)
- จัดการชื่อแก๊ง (`#gang-name`), คำขวัญ, คำสั่ง Connect IP, ลิงก์ Discord

- เพิ่ม ลบ แก้ไขสมาชิกแก๊ง พร้อมอัปโหลดรูปโปรไฟล์
- **ระบบ Template หลายแก๊ง (Presets):** บันทึกการตั้งค่าเป็นแก๊งใหม่ และสลับใช้ระหว่างหลายๆ แก๊งได้ในคลิกเดียว
